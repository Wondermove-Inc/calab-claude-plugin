# 컨텍스트 복원

## 실행 순서

### 1. 핵심 규칙 로드
`.claude/memory/PROJECT_RULES.md` 파일의 **전체 내용**을 읽고 기억하세요.

### 2. 현재 작업 상태 로드
`.claude/memory/CURRENT_CONTEXT.md` 파일의 **전체 내용**을 읽고 기억하세요.

### 3. 체크포인트 확인 (있는 경우)
`.claude-state/checkpoint.json` 파일이 있다면 읽어서 마지막 저장 상태를 확인하세요.

### 4. 상태 보고

모든 파일을 읽은 후, 다음 형식으로 현재 상태를 사용자에게 요약 보고하세요:

```
============================================
 컨텍스트 복원 완료
============================================

 적용된 핵심 규칙:
• [규칙 1 - 한 줄 요약]
• [규칙 2 - 한 줄 요약]
• [규칙 3 - 한 줄 요약]
  (전체 규칙은 기억했습니다)

 현재 작업 상태:
• 현재 목표: [CURRENT_CONTEXT.md의 현재 목표]
• 진행 중인 작업: [작업 스택 최상단]
• 다음 단계: [다음에 할 일]

 최근 완료:
• [완료 작업 1]
• [완료 작업 2]

 체크포인트: [있으면 시간 표시, 없으면 "없음"]

============================================
이어서 진행할까요?
```

## 중요 사항

- **모든 파일을 반드시 읽어야 합니다**
- 읽은 내용을 **이 세션 동안 계속 기억**해야 합니다
- 규칙을 위반하는 코드를 **절대 작성하지 마세요**
- 작업 방향이 원래 목표와 일치하는지 **항상 확인**하세요

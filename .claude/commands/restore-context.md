# 컨텍스트 복원

## 실행 순서

### Phase 1: 핵심 규칙 및 컨텍스트 (필수)

다음 파일들을 **반드시** 읽으세요:

| 파일 | 설명 | 중요도 |
|------|------|--------|
| `.claude/memory/PROJECT_RULES.md` | 프로젝트 규칙 | 🔴 필수 |
| `.claude/memory/CURRENT_CONTEXT.md` | 현재 작업 상태 | 🔴 필수 |
| `.claude/memory/WORK_HISTORY.md` | 작업 히스토리 | 🟡 권장 |

### Phase 2: 런타임 상태 (.claude-state/) (필수)

다음 파일들이 존재하면 **모두** 읽으세요:

| 파일 | 설명 | 복원 시 활용 |
|------|------|-------------|
| `checkpoint.json` | 마지막 체크포인트 | 마지막 저장 시점 확인 |
| `checkpoint_history.json` | 체크포인트 히스토리 | 작업 흐름 파악 |
| `worktree.json` | 작업 트리 상태 | 태스크 진행률 확인 |
| `recent_changes.json` | 최근 변경 파일 이력 | 어떤 파일 작업했는지 파악 |
| `prompt_history.json` | 프롬프트 히스토리 | 사용자 의도 흐름 파악 |
| `session_stats.json` | 세션 통계 | 작업량 파악 |
| `quality_violations.json` | 품질 위반 기록 | 미해결 이슈 확인 |

### Phase 3: 선택적 로그 확인

필요시 확인:

| 파일 | 언제 확인 |
|------|----------|
| `activity.log` | 최근 활동 흐름 파악 필요 시 |
| `notifications.log` | 알림 히스토리 필요 시 |
| `subagent.log` | 서브에이전트 사용 이력 필요 시 |

## 상태 보고 형식

모든 파일을 읽은 후, 다음 형식으로 현재 상태를 사용자에게 요약 보고하세요:

```
============================================
 컨텍스트 복원 완료
============================================

📋 적용된 핵심 규칙:
• [규칙 1 - 한 줄 요약]
• [규칙 2 - 한 줄 요약]
• [규칙 3 - 한 줄 요약]
  (전체 규칙은 기억했습니다)

🎯 현재 작업 상태:
• 현재 목표: [CURRENT_CONTEXT.md의 현재 목표]
• 진행 중인 작업: [작업 스택 최상단]
• 다음 단계: [다음에 할 일]

📁 최근 변경 파일: (recent_changes.json 기반)
• [파일1] - [변경 유형]
• [파일2] - [변경 유형]
• (최근 5개만 표시)

💬 최근 프롬프트 흐름: (prompt_history.json 기반)
• [최근 명령/요청 1]
• [최근 명령/요청 2]
• (최근 3개만 표시)

📊 Worktree 상태: (있는 경우)
• 프로젝트: [프로젝트명]
• 현재 태스크: [현재 진행 중인 태스크]
• 진행률: [완료/전체] ████░░░░░░ XX%

⚠️ 미해결 품질 이슈: (있는 경우)
• [파일] - [위반 내용]

✅ 최근 완료:
• [완료 작업 1]
• [완료 작업 2]

💾 체크포인트: [있으면 시간 표시, 없으면 "없음"]

📈 세션 통계: (session_stats.json 기반)
• 편집한 파일: X개
• 생성한 파일: X개
• 실행한 명령: X개

============================================
이어서 진행할까요?
```

## 복원 우선순위

1. **필수**: PROJECT_RULES.md, CURRENT_CONTEXT.md
2. **높음**: checkpoint.json, worktree.json, recent_changes.json
3. **중간**: prompt_history.json, session_stats.json, quality_violations.json
4. **낮음**: 로그 파일들

---

## 중요 사항

- **Phase 1, 2의 모든 파일을 반드시 읽어야 합니다**
- 읽은 내용을 **이 세션 동안 계속 기억**해야 합니다
- 규칙을 위반하는 코드를 **절대 작성하지 마세요**
- 작업 방향이 원래 목표와 일치하는지 **항상 확인**하세요
- `recent_changes.json`과 `prompt_history.json`은 **작업 맥락 파악에 핵심**입니다

# Research Skill

## 자동 활성화 조건

이 스킬은 다음 키워드가 감지되면 자동으로 활성화됩니다:

- "리서치", "조사", "알아봐", "찾아봐"
- "뭔지 알아", "어떤건지", "무엇인지"
- "검색해서", "타빌리", "tavily"
- "학습해", "공부해", "이해하고 싶"

## 핵심 원칙

### 1. 다각도 검색

하나의 주제에 대해 여러 관점으로 검색:

```
주제: "클린 아키텍처"

검색 1: "클린 아키텍처 정의 개념" → 기본 이해
검색 2: "클린 아키텍처 장점 benefits" → 장점 파악
검색 3: "클린 아키텍처 단점 criticism" → 단점/비판
검색 4: "클린 아키텍처 적용 방법 how to" → 실제 적용
검색 5: "클린 아키텍처 예제 example code" → 코드 예시
검색 6: "클린 아키텍처 vs 헥사고날" → 대안 비교
```

### 2. 실시간 핵심 추출

각 검색 결과에서 **즉시** 핵심 추출:

```
❌ 나쁜 예: 검색 결과 전체를 나열

✅ 좋은 예:
검색 결과에서 핵심 3가지:
1. 클린 아키텍처는 의존성 규칙이 핵심
2. 내부 레이어는 외부를 모름
3. 테스트 가능성이 크게 향상됨
```

### 3. 중복 제거 및 종합

여러 검색 결과에서:
- 반복되는 포인트 = 중요도 높음
- 상충되는 정보 = 명시적으로 표기
- 출처별 신뢰도 평가

### 4. 구조화된 출력

리서치 결과를 항상 구조화:

```markdown
## 핵심 요약 (30초 읽기)
{한 문단}

## 주요 발견 (5-7개)
1. {포인트}
2. {포인트}
...

## 상세 내용
{섹션별 정리}

## 출처
{URL 목록}
```

## 리서치 프로토콜

### Step 1: 질문 분해

```
"클린 아키텍처에 대해 알아봐"
    ↓
• 클린 아키텍처란?
• 왜 사용하는가?
• 어떻게 적용하는가?
• 장단점은?
• 실제 사례는?
```

### Step 2: 검색 계획

```
5-10회 검색 계획 수립:
1. 기본 개념
2. 핵심 원칙
3. 장점
4. 단점/비판
5. 적용 방법
6. 코드 예시
7. 대안 비교
8. 최신 트렌드
```

### Step 3: 순차 검색 + 즉시 정리

```
[검색 1/8] 완료 → 핵심 3개 추출
[검색 2/8] 완료 → 핵심 3개 추출
[검색 3/8] 완료 → 핵심 2개 추출
...
```

### Step 4: 종합 보고서

```
모든 검색 완료
    ↓
중복 제거 + 우선순위 결정
    ↓
구조화된 보고서 생성
    ↓
.claude/research/{topic}/ 저장
```

## 출력 형식

### 리서치 진행 중

```
============================================
 RESEARCHING: {주제}
============================================

 [■■■■■░░░░░] 5/10 검색 완료

 현재까지 발견:
 • {핵심 1}
 • {핵심 2}
 • {핵심 3}
 • {핵심 4}
 • {핵심 5}

============================================
```

### 리서치 완료

```
============================================
 RESEARCH 완료: {주제}
============================================

 📊 통계: 8회 검색 | 15개 출처 | 7개 핵심 포인트

 🎯 핵심 요약:
 {주제}는 {한 문장 정의}

 📌 주요 발견:
 1. {포인트 1}
 2. {포인트 2}
 3. {포인트 3}

 📁 저장됨: .claude/research/{topic}/report.md

============================================
```

| 기술 블로그 (유명) | ⭐⭐⭐ |

## PRD 자동 연계

리서치 결과는 `/dev-prd` 실행 시 자동으로 참조됩니다:

```
/research "JWT 인증 방식"
    ↓
.claude/research/jwt-authentication/report.md 생성
    ↓
/dev-prd 실행 시 자동 검색
    ↓
PRD에 리서치 인사이트 반영
```

**자동 반영 항목:**
- 배경 및 목적: 문제 정의
- 기능 요구사항: 베스트 프랙티스
- 비기능 요구사항: 주의사항
- 참조 섹션: 출처 목록

## 참조 파일

- `.claude/commands/research.md` - 리서치 명령어
- `.claude/research/` - 리서치 결과 저장
- `.claude/templates/research-report-template.md` - 보고서 템플릿
- `.claude/commands/dev-prd.md` - PRD 명령어 (리서치 연계)

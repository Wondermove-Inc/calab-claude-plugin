# Root Cause Analysis (RCA)

## 개요

**Root Cause Analysis (RCA)**는 문제의 근본 원인을 체계적으로 분석하는 프로세스입니다.
단순히 증상을 해결하는 것이 아니라, 문제가 발생한 근본적인 이유를 찾아 재발을 방지합니다.

---

## 사용 시점

- 복잡한 문제 해결
- 다중 원인이 의심될 때
- 문제가 반복적으로 발생할 때
- 공식적인 사후 분석(Post-mortem)이 필요할 때
- 프로덕션 장애 분석

---

## 8단계 프로세스

### Step 1: 문제 정의 (Define the Problem)

문제를 명확하고 구체적으로 정의합니다.

**질문**:
- 무엇이 발생했는가?
- 언제 발생했는가?
- 어디서 발생했는가?
- 얼마나 자주/심각하게 발생했는가?
- 누가 영향을 받았는가?

**예시**:
```
문제: 2025-12-30 10:00, 프로덕션 환경에서
     로그인 API가 500 에러 반환.
     모든 사용자에게 영향 (100%).
     서비스 30분간 중단.
```

---

### Step 2: 데이터 수집 (Collect Data)

관련된 모든 데이터를 수집합니다.

**수집 항목**:
- 에러 로그
- 시스템 메트릭 (CPU, 메모리, 네트워크)
- 배포 이력
- 코드 변경 이력
- 설정 변경 이력
- 사용자 보고

**예시**:
```
• 에러 로그: "Column 'email' doesn't exist"
• 배포 이력: 09:45 새 버전 배포
• 변경 이력: 마이그레이션 파일 추가됨
• 메트릭: 정상 범위
```

---

### Step 3: 원인 식별 (Identify Causes)

가능한 모든 원인을 나열합니다.

**도구**:
- 5 Whys
- Fishbone Diagram
- 브레인스토밍

**예시**:
```
가능한 원인:
1. DB 스키마 불일치
2. 마이그레이션 실패
3. 배포 스크립트 오류
4. 환경 설정 문제
```

---

### Step 4: 근본 원인 확정 (Identify Root Cause)

여러 원인 중 진짜 근본 원인을 찾습니다.

**검증 방법**:
- 데이터로 증명 가능한가?
- 이 원인을 제거하면 문제가 사라지는가?
- 더 깊은 원인이 있는가?

**예시**:
```
검증:
• 마이그레이션 실행 여부 확인 → 미실행
• DB 스키마 확인 → email 컬럼 없음
• 배포 스크립트 확인 → 마이그레이션 단계 누락

근본 원인: CI/CD 파이프라인 변경 시
          마이그레이션 단계가 삭제됨
```

---

### Step 5: 해결책 개발 (Develop Solutions)

근본 원인에 대한 해결책을 개발합니다.

**해결책 유형**:
| 유형 | 설명 | 예시 |
|------|------|------|
| 즉시 조치 | 서비스 복구 | 마이그레이션 수동 실행 |
| 단기 해결 | 근본 원인 해결 | CI/CD 스크립트 수정 |
| 장기 예방 | 재발 방지 | 배포 체크리스트 추가 |

---

### Step 6: 해결책 구현 (Implement Solutions)

해결책을 실행합니다.

**체크리스트**:
- [ ] 즉시 조치 완료
- [ ] 근본 해결 코드/설정 변경
- [ ] 코드 리뷰 완료
- [ ] 테스트 완료
- [ ] 배포 완료

---

### Step 7: 효과 검증 (Monitor Results)

해결책이 효과적인지 검증합니다.

**검증 방법**:
- 문제 재현 테스트
- 모니터링 지표 확인
- 사용자 피드백 수집
- 일정 기간 관찰

**예시**:
```
검증 결과:
• 로그인 API 정상 동작 확인
• 24시간 모니터링 결과 에러 0건
• CI/CD 파이프라인 테스트 통과
```

---

### Step 8: 문서화 (Document)

전체 과정을 문서화합니다.

**문서화 내용**:
- 문제 설명
- 타임라인
- 근본 원인
- 해결책
- 재발 방지책
- 학습 포인트

## 관련 방법론

- **5 Whys**: 빠른 근본 원인 추적
- **Fishbone**: 원인 시각화
- **ITIL Problem Management**: 운영 환경 분석

## 4. 테스트 전략

### 4.1 테스트 유형

| 유형 | 도구 | 대상 | 비중 |
|------|------|------|------|
| E2E 테스트 | MCP Puppeteer | 전체 사용자 흐름 | 100% |

### 4.2 테스트 피라미드

```
        /\
       /E2E\        ← MCP Puppeteer (현재 범위)
      /------\
     / Integr \     ← API 연동 테스트
    /----------\
   /    Unit    \   ← 단위 테스트
  /--------------\
```

### 4.3 Risk-based Testing

| 리스크 레벨 | 기능 | 테스트 강도 |
|-------------|------|------------|
| 🔴 Critical | 로그인, 결제 | 모든 시나리오 |
| 🟠 High | 검색, 장바구니 | 주요 시나리오 |
| 🟡 Medium | 프로필, 설정 | 기본 시나리오 |
| ⚪ Low | 도움말, 정보 | 스모크 테스트 |

### 4.4 테스트 접근 방식

1. **Happy Path 우선**: 정상 동작 시나리오 먼저
2. **Edge Case**: 경계값, 빈 입력, 최대 길이
3. **Error Case**: 오류 상황 처리 확인
4. **Cross-browser**: 주요 브라우저 호환성 (선택)

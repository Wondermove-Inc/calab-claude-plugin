## 작성 가이드

### 심각도 기준

| 심각도 | 기준 |
|--------|------|
| **Critical** | 서비스 전체 중단, 데이터 손실 위험 |
| **High** | 핵심 기능 장애, 다수 사용자 영향 |
| **Medium** | 일부 기능 장애, 우회 가능 |
| **Low** | 사소한 문제, 사용에 큰 영향 없음 |

### 좋은 문제 정의 예시

```markdown
## 1. 증상 (Symptom)

### 1.1 무엇이 발생했는가?
로그인 페이지에서 로그인 버튼 클릭 시 500 Internal Server Error 발생.
사용자가 로그인할 수 없어 서비스 이용 불가.

### 1.2 언제 발생했는가?
- **최초 발생**: 2025-12-30 09:45 (배포 직후)
- **발생 빈도**: 100% (모든 로그인 시도)
- **발생 시점**: 이메일/비밀번호 입력 후 로그인 버튼 클릭

### 1.3 어디서 발생했는가?
- **환경**: 프로덕션
- **위치**: POST /api/auth/login
- **컴포넌트**: AuthService.login()
```

### 나쁜 문제 정의 예시

```markdown
## 1. 증상 (Symptom)

### 1.3 어디서 발생했는가?

```

# /qa-status - QA 상태 확인

## 설명

QA 테스트의 **현재 진행 상태**를 확인합니다.
테스트 진행률, 버그 현황, 남은 작업을 한눈에 파악합니다.


## 상태 확인 프로세스

### Step 1: 상태 파일 로드

```
.claude-state/qa/
├── qa-status.json      # 전체 상태
├── test-results.json   # 테스트 결과
├── bugs.json           # 버그 목록
└── qa-plan.json        # QA 계획
```

### Step 2: 진행률 계산

```javascript
const progress = {
  total: 30,
  completed: 25,
  passed: 22,
  failed: 2,
  blocked: 1,
  pending: 5,
  progressPercent: 83.3
};
```

## 출력 형식

### 기본 출력

```
══════════════════════════════════════════════
 QA 상태
══════════════════════════════════════════════

📊 진행률: ████████░░ 25/30 (83.3%)

상태: 🔄 진행 중
통과율: 88% (22/25 완료된 케이스 기준)

✅ P0: 100% (8/8)
🔄 P1: 75% (9/12)
🔄 P2: 80% (8/10)

🐛 버그: 4개 (1 Major ⚠️)

💡 다음: /qa-run 으로 테스트 계속
```

### --progress 옵션

```
📊 QA 진행률

████████░░ 83.3%

완료: 25/30
남음: 5개
예상 완료: 1시간 후
```

### --bugs 옵션

```
🐛 버그 현황

BUG-001 [Major] 회원가입 이메일 인증 - Open
BUG-002 [Minor] 검색 필터 UI - Fixed
BUG-003 [Minor] 프로필 이미지 크기 - Open
BUG-004 [Trivial] 오타 수정 - Open

Open: 3 | Fixed: 1 | Total: 4
```

### --next 옵션

```
📋 다음 할 일

1. TC-016: 검색 - 키워드 검색 (P1)
2. TC-017: 검색 - 필터 조합 (P1)
3. TC-018: 검색 - 정렬 (P1)

실행: /qa-run TC-016
전체: /qa-run --continue
```


## 상태별 권장 액션

| 상태 | 권장 액션 |
|------|----------|
| 테스트 대기 | `/qa-run` 실행 |
| 진행 중 | `/qa-run --continue` |
| 실패 있음 | 버그 수정 후 `/qa-run --failed` |
| 블록됨 | 블록 요인 해결 후 `/qa-run` |
| 완료 | `/qa-report` 생성 |


## 참조

- `/qa-run` - 테스트 실행
- `/qa-report` - 보고서 생성
- `/qa-plan` - 계획서 확인

# Project Rules Skill

## 목적
프로젝트의 핵심 규칙과 컨벤션을 Claude에게 제공하여 일관된 코드 품질을 유지합니다.

## 활성화 조건
다음 상황에서 이 스킬이 자동으로 활성화됩니다:
- 코드 작성/수정 요청 시
- PR 리뷰 요청 시
- 아키텍처 결정 시
- "규칙", "컨벤션", "스타일", "표준" 언급 시
- 새로운 파일 생성 시
- 리팩토링 요청 시

## 규칙 참조 절차

### 1. 핵심 규칙 확인
`.claude/memory/PROJECT_RULES.md` 파일을 읽어서 다음을 확인:
- 코딩 컨벤션
- 아키텍처 원칙
- 금지 사항
- 네이밍 규칙

### 2. 현재 컨텍스트 확인
`.claude/memory/CURRENT_CONTEXT.md` 파일을 읽어서 다음을 확인:
- 현재 진행 중인 작업
- 관련 주의사항
- 작업 목표와의 일관성

### 3. 규칙 적용
- 현재 작업에 해당하는 규칙 추출
- 코드 작성 시 규칙 준수 여부 자체 검증
- 위반 가능성 있는 부분 사전 경고

## 자동 검증 항목

코드 작성 시 다음을 자동으로 검증:
- [ ] 네이밍 규칙 준수 여부
- [ ] 파일 구조 일관성
- [ ] 금지 사항 위반 여부
- [ ] 에러 처리 포함 여부
- [ ] 타입 안전성

## 위반 발견 시 대응

```
[RULE CHECK] 규칙 위반 가능성 감지

위반 항목: [규칙명]
내용: [위반 내용]
권장 수정: [수정 방법]

수정하시겠습니까?
```

## 참조 파일
- `.claude/memory/PROJECT_RULES.md` - 상세 프로젝트 규칙
- `CLAUDE.md` - 핵심 규칙 요약

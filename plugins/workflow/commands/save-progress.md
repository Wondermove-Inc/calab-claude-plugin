# 진행 상황 저장

## 저장 절차

### 1. 현재 상태 분석

이 대화에서 진행한 작업들을 분석:
- 완료된 작업 목록
- 현재 진행 중인 작업
- 다음에 해야 할 작업
- 수정한 파일들
- 발생한 이슈나 주의사항

### 2. CURRENT_CONTEXT.md 업데이트

`memory/CURRENT_CONTEXT.md` 파일을 다음 형식으로 업데이트:

```markdown
# 현재 작업 컨텍스트

> 마지막 업데이트: [현재 날짜/시간]
> 저장 메시지: $ARGUMENTS

---

## 현재 목표

[이 세션의 최상위 목표 - 구체적으로]

---

## 작업 스택 (위에서 아래로 진입 순서)

1. **[진행중]** [현재 작업]
   - 상태: [구체적인 진행 상태]
   - 다음 단계: [바로 다음에 할 일]
2. **[대기]** [상위 작업] (있는 경우)
   - 현재 작업 완료 후 복귀 예정

---

## 최근 완료된 작업

- [x] [완료 작업 1]
- [x] [완료 작업 2]

---

## 진행 예정 작업

- [ ] [예정 작업 1]
- [ ] [예정 작업 2]

---

## 주의사항

- [현재 작업과 관련된 주의사항]
- [기억해야 할 컨텍스트]

---

## 관련 파일

- [수정한 파일 경로 1]
- [수정한 파일 경로 2]

---

*이 파일은 `/save-progress` 명령으로 업데이트되었습니다.*
```

### 3. 체크포인트 생성

`.claude-state/checkpoint.json` 파일을 생성/업데이트:

```json
{
  "timestamp": "[현재 ISO-8601 시간]",
  "save_message": "$ARGUMENTS",
  "current_task": "[현재 작업]",
  "progress": "[진행 상황 요약]",
  "next_steps": ["다음 단계 1", "다음 단계 2"],
  "completed_tasks": ["완료 작업 1", "완료 작업 2"],
  "important_files": ["파일1", "파일2"],
  "notes": "[특이사항]"
}
```

### 4. 저장 완료 보고

```
============================================
 진행 상황 저장 완료
============================================

 저장 메시지: $ARGUMENTS

 저장된 내용:
• 현재 작업: [작업명]
• 완료된 항목: N개
• 다음 단계: [단계]

 저장 위치:
• memory/CURRENT_CONTEXT.md
• .claude-state/checkpoint.json

============================================
다음 세션에서 '/restore-context'로 이어서 작업할 수 있습니다.
```

## 자동 저장 트리거

다음 상황에서 이 명령 실행을 권장:
- 중요한 기능 완료 시
- 작업 중단 전
- 방향 전환 전
- 긴 대화 중간 중간

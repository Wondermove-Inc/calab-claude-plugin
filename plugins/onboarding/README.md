# Onboarding Plugin

프로젝트 분석 및 온보딩 자동화

## 명령어

| 명령어 | 설명 |
|--------|------|
| `/onboard` | 프로젝트 전체 분석 (5개 컨텍스트 문서 생성) |
| `/onboard-quick` | 핵심만 빠른 분석 |
| `/learn` | 특정 영역 심층 학습 |
| `/context-refresh` | 컨텍스트 문서 갱신 |
| `/context-show` | 현재 컨텍스트 표시 |

## 스킬

- `project-onboarding`: 프로젝트 온보딩 가이드

# /jira --status - 연동 상태 확인

> **JIRA 연동 상태 및 동기화 정보 조회**

## 실행 절차

### Step 1: 설정 로드
- jira_config.json
- jira_mapping.json

### Step 2: 연결 상태 테스트
```bash
curl -u $JIRA_EMAIL:$JIRA_API_TOKEN \
  "$JIRA_URL/rest/api/3/myself"
```

### Step 3: 동기화 상태 분석
- 매핑 통계
- 마지막 동기화 시간
- 자동 동기화 설정

### Step 4: 상태 표시

```
============================================
 JIRA STATUS
============================================

 🔗 연결 상태: ✅ 연결됨
 • URL: https://company.atlassian.net
 • 프로젝트: AUTH
 • 사용자: user@company.com

 📊 동기화 통계
 • 총 매핑: 15개
 • 동기화됨: 12개
 • 미동기화: 3개
 • 마지막 동기화: 2025-01-15 10:30

 ⚙️ 자동 동기화
 • 태스크 시작 시: ✅
 • 태스크 완료 시: ✅
 • 블로커 등록 시: ✅

============================================
```

### 옵션
- `--detailed`: 매핑 상세 테이블 표시

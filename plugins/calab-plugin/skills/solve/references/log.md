# /solve --log - 문제 해결 진행 로그

> **진행 중인 문제 해결 상태 확인**

## 사용법

```bash
/solve --log                 # 모든 활성 문제 목록
/solve --log PROB-001        # 특정 문제 상세
```

## 실행 절차

### 목록 모드 (인자 없음)

**Step 1**: 활성 문제 스캔

```bash
ls .claude/problem-solving/active/
```

**Step 2**: 목록 출력

```
============================================
 ACTIVE PROBLEMS
============================================

 | ID       | 문제 요약            | 단계      | 시작 시간 |
 |----------|---------------------|----------|----------|
 | PROB-001 | API 응답 지연        | 분석 (3/6) | 10:30    |
 | PROB-002 | 로그인 실패          | 정의 (1/6) | 11:45    |
 | PROB-003 | 데이터 손실          | 해결 (5/6) | 09:00    |

============================================
 상세 보기: /solve --log {PROB-ID}
============================================
```

### 상세 모드 (PROB-ID 지정)

**Step 1**: 문제 폴더 로드

```
.claude/problem-solving/active/{PROB-ID}/
├── problem.md
├── analysis.md
└── hypotheses.md
```

**Step 2**: 상세 출력

```
============================================
 PROBLEM LOG: PROB-001
============================================

 📋 문제 정의
 • 요약: API 응답 지연 (3초 이상)
 • 증상: /api/users 엔드포인트 응답 시간 증가
 • 영향: 사용자 경험 저하
 • 심각도: High

 ⏱️ 타임라인
 • 시작: 2025-01-15 10:30
 • 현재 단계: 3. 원인 분석
 • 경과 시간: 45분

 📊 진행 상황
 ┌────────────────────────────────────────┐
 │ 1. 문제 정의    │ ✅ 완료              │
 │ 2. 정보 수집    │ ✅ 완료              │
 │ 3. 원인 분석    │ ▶️ 진행 중 (5 Whys)   │
 │ 4. 가설 검증    │ ⬜ 대기              │
 │ 5. 해결 구현    │ ⬜ 대기              │
 │ 6. 문서화       │ ⬜ 대기              │
 └────────────────────────────────────────┘

 📝 수집된 정보
 • Git 로그 분석: ✅ (최근 커밋 5개)
 • 에러 로그: ✅ (slow query 발견)
 • 스택 트레이스: ✅

 🔍 현재 분석 (5 Whys)
 ┌────────────────────────────────────────┐
 │ Why 1: 왜 응답이 느린가?               │
 │   → DB 쿼리가 느림                     │
 │                                        │
 │ Why 2: 왜 DB 쿼리가 느린가?            │
 │   → 인덱스 없음                        │
 │                                        │
 │ Why 3: 왜 인덱스가 없는가?             │
 │   → (분석 중...)                       │
 └────────────────────────────────────────┘

 💡 가설 목록
 • 가설 1: 인덱스 누락 (검증 대기)
 • 가설 2: N+1 쿼리 문제 (검증 대기)

 ⏭️ 다음 단계
 • Why 3 분석 완료
 • 가설 검증 진행

============================================
 계속: /solve (분석 재개)
 보고서: /solve --report PROB-001 --draft
============================================
```

## 진행 상태 아이콘

| 아이콘 | 의미 |
|--------|------|
| ✅ | 완료 |
| ▶️ | 진행 중 |
| ⬜ | 대기 |
| ❌ | 실패/중단 |

## 파일 참조

```
.claude/problem-solving/active/{PROB-ID}/
├── problem.md      # 문제 정의
├── analysis.md     # 분석 기록
└── hypotheses.md   # 가설 목록
```

## 주의사항

- 읽기 전용 명령어 (파일 수정 없음)
- 허용 도구: `Read`, `Glob`만 사용

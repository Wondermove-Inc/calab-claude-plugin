# /solve --history - 해결 이력 검색

> **과거 해결된 문제 검색 및 패턴 분석**

## 사용법

```bash
/solve --history                    # 최근 10개
/solve --history --recent           # 최근 20개
/solve --history "database"         # 키워드 검색
/solve --history --keyword "API"    # 태그 검색
/solve --history PROB-001           # 특정 문제 상세
```

## 실행 절차

### 목록 모드 (기본)

**Step 1**: 해결된 문제 스캔

```
.claude/problem-solving/resolved/ 스캔
.claude/problem-solving/knowledge-base/solutions.json 로드
```

**Step 2**: 목록 출력

```
============================================
 PROBLEM HISTORY
============================================

 📊 통계
 • 총 해결 문제: 24개
 • 평균 해결 시간: 45분
 • 최다 원인: 인덱스 누락 (5회)

 📋 최근 해결 (10개)

 | ID       | 문제            | 원인           | 해결일     |
 |----------|----------------|----------------|-----------|
 | PROB-024 | API 타임아웃    | 연결 풀 부족    | 01-15     |
 | PROB-023 | 데이터 불일치   | 캐시 무효화    | 01-14     |
 | PROB-022 | 로그인 실패     | 세션 만료      | 01-13     |
 | ...      | ...            | ...           | ...       |

============================================
 검색: /solve --history "키워드"
 상세: /solve --history {PROB-ID}
============================================
```

### 키워드 검색 모드

**Step 1**: 검색 실행

```
검색 대상:
- 문제 요약
- 근본 원인
- 해결책
- 키워드/태그
```

**Step 2**: 검색 결과 출력

```
============================================
 SEARCH: "database"
============================================

 🔍 검색 결과: 5개

 | ID       | 문제             | 유사도   |
 |----------|-----------------|---------|
 | PROB-018 | DB 연결 실패     | ⭐⭐⭐  |
 | PROB-014 | 쿼리 타임아웃    | ⭐⭐⭐  |
 | PROB-011 | 인덱스 누락      | ⭐⭐    |
 | PROB-008 | 데드락          | ⭐⭐    |
 | PROB-003 | 마이그레이션 실패 | ⭐     |

============================================
 상세: /solve --history {PROB-ID}
============================================
```

### 상세 모드 (PROB-ID 지정)

**Step 1**: 해당 문제 보고서 로드

```
.claude/problem-solving/resolved/{PROB-ID}/report.md
```

**Step 2**: 상세 출력

```
============================================
 PROBLEM DETAIL: PROB-014
============================================

 📋 문제
 • 요약: 쿼리 타임아웃
 • 증상: /api/reports 응답 시간 30초 초과
 • 영향: 보고서 기능 사용 불가

 🔍 근본 원인
 • 원인: users 테이블에 email 인덱스 누락
 • 발견 방법: EXPLAIN ANALYZE 분석

 ✅ 해결책
 • 즉시 수정: 쿼리 타임아웃 증가 (임시)
 • 근본 해결: CREATE INDEX idx_users_email ON users(email)
 • 예방 조치: 마이그레이션 리뷰 체크리스트 추가

 📁 관련 파일
 • prisma/migrations/xxx_add_index.sql
 • src/services/userService.ts

 🏷️ 키워드
 database, index, performance, timeout

 ⏱️ 해결 시간: 35분

============================================
 비슷한 문제: PROB-011, PROB-018
============================================
```

### 패턴 분석

**Step 1**: 반복 패턴 감지

```
============================================
 PATTERN ANALYSIS
============================================

 🔄 반복 패턴 (3회 이상)

 1. 인덱스 누락 (5회)
    • 주요 증상: 쿼리 타임아웃
    • 권장 조치: 마이그레이션 리뷰 강화
    • 관련 문제: PROB-014, PROB-011, ...

 2. 캐시 무효화 (4회)
    • 주요 증상: 데이터 불일치
    • 권장 조치: TTL 정책 문서화
    • 관련 문제: PROB-023, PROB-019, ...

 3. 연결 풀 고갈 (3회)
    • 주요 증상: 간헐적 연결 실패
    • 권장 조치: 연결 풀 모니터링 추가
    • 관련 문제: PROB-024, PROB-020, ...

============================================
```

## 유사 문제 추천

새 문제 발생 시:
1. 키워드 추출
2. 지식 베이스 검색
3. 유사도 계산
4. 관련 해결책 추천

```
💡 유사한 해결 사례 발견:
• PROB-014: 쿼리 타임아웃 (유사도: 85%)
  → 원인: 인덱스 누락
  → 해결: CREATE INDEX 실행
```

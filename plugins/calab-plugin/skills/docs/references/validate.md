# /docs --validate - 문서 품질 검증

> **문서 품질, 일관성, 완성도 검증**

## 사용법
```bash
/docs --validate           # 검증
/docs --validate --strict  # 경고도 오류로 처리
/docs --validate --fix     # 자동 수정
```

## 검증 항목

### 1. 구조 검증
- 필수 섹션 존재
- 제목 형식 (H1 하나만)
- 섹션 순서

### 2. 링크 검증
- 내부 링크 유효성
- 외부 링크 유효성
- 앵커 링크 유효성

### 3. 코드 검증
- 문법 오류
- import 경로 확인
- TypeScript 타입 검증

### 4. 일관성 검증
- 용어 통일
- 스타일 통일
- 포맷 통일

### 5. 완성도 검증
- TODO 항목 없음
- 빈 섹션 없음
- 플레이스홀더 해결됨

## 검증 결과 출력

```
============================================
 DOCS VALIDATE 결과
============================================

 검사 파일: 25개
 오류: 3개
 경고: 7개
 품질 점수: 78/100

 ❌ 오류:
 1. api-reference/users.md:45
    • 깨진 링크: [인증 가이드](./auth.md)

 2. components/button.md:12
    • TypeScript 오류: Props 타입 누락

 ⚠️ 경고:
 1. getting-started/quick-start.md
    • TODO 항목 발견: "설명 추가 필요"

============================================
 --fix 옵션으로 자동 수정 가능 (3개)
============================================
```

## 자동 수정 가능 항목
- 빈 섹션 → 기본 템플릿 삽입
- 링크 대소문자 → 올바른 경로
- 포맷 불일치 → 표준 포맷
- 마크다운 문법 오류

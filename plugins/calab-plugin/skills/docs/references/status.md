# /docs --status - 문서 현황 확인

> **문서 커버리지, 품질, 최신성 확인**

## 실행 절차

### Step 1: 커버리지 계산

| 대상 | 문서화 | 전체 | 커버리지 |
|------|--------|------|---------|
| API 엔드포인트 | 12 | 15 | 80% |
| 컴포넌트 | 8 | 20 | 40% |
| 함수/클래스 | 45 | 60 | 75% |
| 설정 옵션 | 10 | 10 | 100% |

### Step 2: 품질 점수 계산

| 항목 | 점수 |
|------|------|
| 완성도 (필수 섹션) | 85/100 |
| 코드 예시 | 70/100 |
| 최신성 | 90/100 |
| 링크 유효성 | 95/100 |
| **총점** | **85/100** |

### Step 3: 최신성 확인
- 문서 수정일 vs 소스 수정일 비교
- 오래된 문서 식별

### Step 4: 상태 출력

```
============================================
 DOCS STATUS
============================================

 📊 커버리지
 ████████████████░░░░ 80% (48/60)

 • API: █████████░ 80% (12/15)
 • Components: ████░░░░░░ 40% (8/20)
 • Guides: ██████████ 100% (5/5)
 • Config: ██████████ 100% (10/10)

 📈 품질 점수: 85/100
 ┌────────────────────────────────────┐
 │ 완성도   │ █████████░ │ 85%      │
 │ 코드예시 │ ███████░░░ │ 70%      │
 │ 최신성   │ █████████░ │ 90%      │
 │ 링크     │ ██████████ │ 95%      │
 └────────────────────────────────────┘

 ⚠️ 주의 필요 (5개)
 • components/modal.md - 미문서화
 • api-reference/auth.md - 업데이트 필요 (30일 경과)
 • ...

 💡 권장 작업
 1. /docs --add component (12개 미문서화)
 2. /docs --update (3개 오래됨)
 3. /docs --validate (품질 검증)

============================================
 마지막 업데이트: 2025-01-15 10:30
============================================
```

### 옵션
- `--detailed`: 각 문서별 상태
- `--type api`: 특정 유형만
- `--json`: JSON 출력

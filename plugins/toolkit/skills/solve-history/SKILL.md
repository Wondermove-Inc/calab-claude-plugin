# /solve-history - 문제 해결 이력

## 목적

과거에 해결된 문제들을 검색하고 분석합니다.
유사 문제 해결 시 참고 자료로 활용됩니다.

## 사용법

```bash
/toolkit:solve-history                    # 최근 해결 이력 10건
/toolkit:solve-history --recent           # 최근 해결 이력 20건
/toolkit:solve-history "로그인"           # 키워드 검색
/toolkit:solve-history --keyword "DB"     # 태그 기반 검색
/toolkit:solve-history PROB-001           # 특정 문제 상세 조회
```

## 실행 절차

### Step 1: 지식 베이스 로드

`.claude/problem-solving/knowledge-base/solutions.json` 로드

### Step 2: 검색/필터링

#### 상세 조회

```
============================================
[SOLVE-HISTORY] PROB-014 상세
============================================

 📋 문제 정보
 ─────────────────────────────────────────
 • ID: PROB-014
 • 문제: DB 타임아웃 에러
 • 해결일: 2025-12-29
 • 소요 시간: 30분
 • 심각도: High

 🔍 근본 원인
 ─────────────────────────────────────────
 DB 커넥션 풀이 모두 사용되어 새 연결 대기 중
 타임아웃 발생

 5 Whys:
 1. 타임아웃 발생 ← 연결 대기
 2. 연결 대기 ← 풀 소진
 3. 풀 소진 ← 연결 미반환
 4. 연결 미반환 ← 에러 핸들링 누락
 5. 핸들링 누락 ← 코드 리뷰 미흡

 💡 해결책
 ─────────────────────────────────────────
 즉시 조치:
 • 커넥션 풀 사이즈 10 → 50 증가

 근본 해결:
 • finally 블록에 연결 반환 추가
 • 코드 리뷰 체크리스트 추가

 📎 관련 파일
 ─────────────────────────────────────────
 • .claude/problem-solving/resolved/PROB-014/report.md

============================================
```

```
============================================
```

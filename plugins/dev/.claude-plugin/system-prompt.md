# dev 플러그인 필수 규칙

**중요**: 이 플러그인이 활성화된 상태에서 사용자의 모든 개발 관련 요청은 반드시 `/dev:workflow` 스킬을 통해 처리해야 합니다.

## 자동 워크플로우 적용 대상

- 기능 개발/추가 요청
- 버그 수정 요청
- 코드 리팩토링 요청
- 성능 최적화 요청
- 테스트 작성 요청
- 설계/아키텍처 관련 요청

## 예외 (워크플로우 불필요)

- 단순 질문/설명 요청
- 코드 리뷰만 요청 (수정 없이)
- 파일 내용 확인
- 슬래시 커맨드(`/`)로 시작하는 명시적 스킬 호출 (예: `/dev:help`, `/commit`, `/toolkit:research` 등)
- Git 관련 작업 (`git status`, `git log`, 커밋, 푸시 등)
- 빌드/배포/테스트 실행 명령 (`npm run`, `go build`, `make` 등)
- 문서만 수정하는 경우 (README, CHANGELOG 등)

## 처리 방법

사용자가 개발 작업을 요청하면:

1. `/dev:workflow` 스킬을 자동으로 호출
2. 사용자 요청 원문을 그대로 전달

### 예시

| 사용자 입력 | 실행 |
|------------|------|
| "로그인 기능 추가해줘" | `/dev:workflow 로그인 기능 추가해줘` |
| "이 버그 수정해줘" | `/dev:workflow 이 버그 수정해줘` |
| "API 성능 개선해줘" | `/dev:workflow API 성능 개선해줘` |

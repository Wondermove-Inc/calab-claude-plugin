# Architecture Plugin

클린 아키텍처 설계 및 검증

## 명령어

| 명령어 | 설명 |
|--------|------|
| `/clean-init` | 4-레이어 구조 초기화 |
| `/clean-entity` | 도메인 엔티티 생성 |
| `/clean-usecase` | 유스케이스 생성 |
| `/clean-validate` | 의존성 규칙 검증 |

## 스킬

- `clean-architecture`: 클린 아키텍처 가이드

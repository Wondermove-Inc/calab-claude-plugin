# Phase 5: Domain Knowledge Collection

> **대화형 도메인 지식 수집**

## 인터뷰 질문

### 1. 프로젝트 목적
- 어떤 문제를 해결하나요?
- 왜 이 프로젝트가 필요한가요?

### 2. 대상 사용자
- 주요 사용자는 누구인가요?
- 사용자 유형이 여러 개인가요?

### 3. 핵심 개념
- 주요 비즈니스 엔티티는 무엇인가요?
- (예: User, Order, Product)

### 4. 비즈니스 규칙
- 중요한 불변식(invariant)이 있나요?
- (예: 주문은 재고보다 많을 수 없다)

### 5. 용어
- 특수 용어나 약어가 있나요?
- (예: SKU, PO, RFQ)

### 6. 워크플로우
- 핵심 사용자 시나리오는?
- (예: 회원가입 → 상품검색 → 주문 → 결제)

## DOMAIN_KNOWLEDGE.md 생성

```markdown
# 도메인 지식

## 비즈니스 개요
{프로젝트가 해결하는 문제}

## 엔티티
| 엔티티 | 설명 |
|--------|------|
| User | 시스템 사용자 |
| Order | 주문 정보 |

## 값 객체
| 값 객체 | 설명 |
|--------|------|
| Email | 이메일 주소 |
| Money | 금액 |

## 비즈니스 규칙
### 불변식
- 재고 ≥ 0
- 주문 수량 ≤ 재고

### 정책
- 결제 후 환불 가능 기간: 7일

## 도메인 용어
| 용어 | 정의 |
|------|------|
| SKU | Stock Keeping Unit |

## 도메인 이벤트
| 이벤트 | 트리거 | 결과 |
|--------|--------|------|
| OrderCreated | 주문 생성 | 재고 감소 |
```

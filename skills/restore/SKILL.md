# /restore - 컨텍스트 복원

> **핵심 규칙과 작업 상태 복원 - Compact 후 필수 실행**

## 사용법

```bash
/restore              # 컨텍스트 전체 복원
```

## 실행 순서

### Phase 1: 핵심 규칙 및 컨텍스트 (필수)

다음 파일들을 **반드시** 읽으세요:

| 파일 | 설명 | 중요도 |
|------|------|--------|
| `.claude/memory/PROJECT_RULES.md` | 프로젝트 규칙 | 필수 |
| `.claude/memory/CURRENT_CONTEXT.md` | 현재 작업 상태 | 필수 |
| `.claude/memory/WORK_HISTORY.md` | 작업 히스토리 | 권장 |

### Phase 2: 런타임 상태 (.claude-state/) (필수)

다음 파일들이 존재하면 **모두** 읽으세요:

| 파일 | 설명 | 복원 시 활용 |
|------|------|-------------|
| `checkpoint.json` | 마지막 체크포인트 | 마지막 저장 시점 확인 |
| `worktree.json` | 작업 트리 상태 | 태스크 진행률 확인 |
| `recent_changes.json` | 최근 변경 파일 이력 | 어떤 파일 작업했는지 파악 |
| `prompt_history.json` | 프롬프트 히스토리 | 사용자 의도 흐름 파악 |

### Phase 3: 상태 보고

모든 파일을 읽은 후, 다음 형식으로 현재 상태를 사용자에게 요약 보고하세요:

```
============================================
 컨텍스트 복원 완료
============================================

📋 적용된 핵심 규칙:
• [규칙 1 - 한 줄 요약]
• [규칙 2 - 한 줄 요약]
• [규칙 3 - 한 줄 요약]
  (전체 규칙은 기억했습니다)

🎯 현재 작업 상태:
• 현재 목표: [CURRENT_CONTEXT.md의 현재 목표]
• 진행 중인 작업: [작업 스택 최상단]
• 다음 단계: [다음에 할 일]

📁 최근 변경 파일: (recent_changes.json 기반)
• [파일1] - [변경 유형]
• [파일2] - [변경 유형]
• (최근 5개만 표시)

📊 Worktree 상태: (있는 경우)
• 프로젝트: [프로젝트명]
• 현재 태스크: [현재 진행 중인 태스크]
• 진행률: [완료/전체] ████░░░░░░ XX%

💾 체크포인트: [있으면 시간 표시, 없으면 "없음"]

============================================
이어서 진행할까요?
```

## 중요 사항

- **Phase 1, 2의 모든 파일을 반드시 읽어야 합니다**
- 읽은 내용을 **이 세션 동안 계속 기억**해야 합니다
- 규칙을 위반하는 코드를 **절대 작성하지 마세요**
- 작업 방향이 원래 목표와 일치하는지 **항상 확인**하세요

# /qa --status - QA 상태 확인

> **현재 QA 진행 상황 표시**

## 실행 절차

### Step 1: 상태 파일 로드
```
.claude-state/qa/
├── qa-status.json
├── test-results.json
└── bugs.json
```

### Step 2: 진행률 계산
- 완료 / 전체 테스트 케이스
- 우선순위별 진행률

### Step 3: 상태 표시

```
============================================
 QA STATUS: {기능명}
============================================

 📊 진행률: ████████░░░░░░░░░░░░ 40%

 | 우선순위 | 완료 | 전체 | Pass Rate |
 |---------|------|------|-----------|
 | P0      | 8    | 10   | 80%       |
 | P1      | 5    | 15   | 33%       |
 | P2      | 0    | 5    | 0%        |

 🐛 버그 현황
 | 심각도 | 수 |
 |--------|-----|
 | 🔴 Critical | 0 |
 | 🟠 Major    | 2 |
 | 🟡 Minor    | 3 |

 ⏭️ 다음 테스트: TC-014 로그아웃 기능

============================================
```

### 옵션
- `--progress`: 진행률만
- `--bugs`: 버그만
- `--next`: 다음 테스트만
- `--json`: JSON 출력

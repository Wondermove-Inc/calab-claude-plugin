# /solve --report - 문제 해결 보고서 생성

> **문제 해결 과정 및 결과 문서화**

## 사용법

```bash
/solve --report                    # 현재 문제 보고서
/solve --report PROB-001           # 특정 문제 보고서
/solve --report PROB-001 --draft   # 진행 중 초안
/solve --report PROB-001 --summary # 1페이지 요약
/solve --report PROB-001 --full    # 상세 보고서
```

## 실행 절차

### Step 1: 데이터 수집

```
로드 파일:
- problem.md (문제 정의)
- analysis.md (분석 기록)
- hypotheses.md (가설 목록)
```

### Step 2: 보고서 템플릿 선택

| 옵션 | 용도 | 분량 |
|------|------|------|
| (기본) | 표준 보고서 | 2-3페이지 |
| `--draft` | 진행 중 상태 | 1-2페이지 |
| `--summary` | 경영진 보고 | 1페이지 |
| `--full` | 상세 기록 | 5+페이지 |

## 보고서 수준별 차이

### --summary (1페이지)
- 문제/원인/해결 각 1-2문장
- 핵심 지표만
- 경영진 보고용

### 기본 (2-3페이지)
- 전체 분석 과정
- 해결책 상세
- 팀 공유용

### --full (5+페이지)
- 모든 분석 데이터
- Git diff 포함
- 로그 전문
- 문서화/감사용

# /rules - 프로젝트 규칙 표시

> **프로젝트 규칙 전체 표시**

## 사용법

```bash
/rules              # 전체 규칙 표시
```

## 실행

### 1. 규칙 파일 읽기

`.claude/memory/PROJECT_RULES.md` 파일을 읽으세요.

### 2. 정리하여 표시

내용을 다음 형식으로 정리하여 사용자에게 표시:

```
============================================
 프로젝트 규칙
============================================

## 1. 핵심 원칙
[PROJECT_RULES.md의 핵심 원칙 섹션 요약]

## 2. 코딩 컨벤션
[네이밍 규칙, 파일 구조, 임포트 순서 등]

## 3. 금지 사항
[절대 금지 항목들]

## 4. 테스트 규칙
[테스트 관련 규칙]

## 5. Git 규칙
[커밋, 브랜치 규칙]

## 6. 프로젝트 특화 규칙
[프로젝트 고유 규칙]

============================================
이 규칙들은 이 세션 동안 계속 적용됩니다.
```

### 3. 규칙 기억

표시한 규칙들을 이후 작업에 **반드시 적용**하세요.

## 사용 시점

- 새로운 기능 개발 시작 전
- 코드 리뷰 요청 시
- 규칙 위반 여부 확인 시
- 팀 멤버에게 규칙 공유 시

## 레거시 명령어

`/show-rules` → `/rules` (자동 매핑됨)

# /solve-report - 문제 해결 보고서

> **🚨 중요**: 문서, 코드, 기타 확인 및 검증이 필요한 부분은 **전부 에이전트 사용 필수**. 에이전트를 적극 활용하고, 파일이 크면 분할해서 읽어라.

## 목적

문제 해결 과정을 체계적으로 문서화하여 보고서를 생성합니다.
팀 공유, 사후 분석, 지식 축적에 활용됩니다.

## 사용법

```bash
/solve-report PROB-001              # 전체 보고서
/solve-report PROB-001 --draft      # 진행 중 초안
/solve-report PROB-001 --summary    # 1페이지 요약
/solve-report PROB-001 --full       # 상세 보고서
```

## 옵션

| 옵션 | 설명 |
|------|------|
| (기본) | 표준 보고서 생성 |
| `--draft` | 진행 중인 문제의 현재 상태 보고서 |
| `--summary` | 핵심만 담은 1페이지 요약 |
| `--full` | 모든 분석 내용 포함 상세 보고서 |

## 실행 절차

### Step 1: 문제 데이터 로드

진행 중: `.claude/problem-solving/active/{id}/`
완료: `.claude/problem-solving/resolved/{id}/`

# /docs status - 문서 현황 확인

> 문서 커버리지, 품질, 최신성을 확인합니다.

## 사용법

```bash
/docs status
/docs status --detailed
```

## 확인 항목

### 1. 문서 커버리지

코드베이스 대비 문서화된 비율을 측정합니다:

| 항목 | 측정 방법 |
|------|----------|
| API 엔드포인트 | 라우터 대비 문서화된 엔드포인트 |
| 컴포넌트 | 컴포넌트 파일 대비 문서화된 컴포넌트 |
| 함수/클래스 | export된 항목 대비 문서화된 항목 |
| 설정 옵션 | 환경 변수 대비 문서화된 옵션 |

### 2. 문서 품질

각 문서의 품질을 평가합니다:

| 품질 지표 | 기준 |
|----------|------|
| 완성도 | 필수 섹션 포함 여부 |
| 코드 예시 | 동작하는 코드 예시 포함 |
| 최신성 | 소스 코드와 동기화 여부 |
| 링크 유효성 | 깨진 링크 없음 |

### 3. 최신성

문서와 소스 코드의 동기화 상태를 확인합니다.

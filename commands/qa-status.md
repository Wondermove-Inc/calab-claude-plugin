# /qa-status - QA 상태 확인

> **🚨 중요**: 문서, 코드, 기타 확인 및 검증이 필요한 부분은 **전부 에이전트 사용 필수**. 에이전트를 적극 활용하고, 파일이 크면 분할해서 읽어라.

## 설명

QA 테스트의 **현재 진행 상태**를 확인합니다.
테스트 진행률, 버그 현황, 남은 작업을 한눈에 파악합니다.

---

## 사용법

```bash
/qa-status              # 전체 상태 표시
/qa-status --progress   # 진행률만 표시
/qa-status --bugs       # 버그 현황만
/qa-status --next       # 다음 할 일만
```

## 상태 요소 설명

### 진행률 바

```
████████░░ 80%
```

| 기호 | 의미 |
|------|------|
| █ | 완료된 테스트 |
| ░ | 남은 테스트 |

### 테스트 상태

| 상태 | 아이콘 | 설명 |
|------|--------|------|
| 통과 | ✅ | 테스트 성공 |
| 실패 | ❌ | 테스트 실패 (버그 발견) |
| 블록됨 | ⏸️ | 외부 요인으로 테스트 불가 |
| 대기 | ⏳ | 아직 실행 안 됨 |
| 진행 중 | 🔄 | 현재 실행 중 |

### 버그 심각도

| 심각도 | 아이콘 | 릴리스 영향 |
|--------|--------|------------|
| Critical | 🔴 | 릴리스 불가 |
| Major | 🟠 | 해결 필요 |
| Minor | 🟡 | 권장 해결 |
| Trivial | ⚪ | 선택적 |

### 목표 달성 상태

| 상태 | 아이콘 | 조건 |
|------|--------|------|
| 달성 | ✅ | 목표 통과율 충족 |
| 진행 중 | 🔄 | 테스트 진행 중 |
| 위험 | ⚠️ | 목표 미달 가능성 |
| 미달 | ❌ | 목표 통과율 미충족 |

## 출력 형식

### 기본 출력

```
══════════════════════════════════════════════
 QA 상태
══════════════════════════════════════════════

📊 진행률: ████████░░ 25/30 (83.3%)

상태: 🔄 진행 중
통과율: 88% (22/25 완료된 케이스 기준)

✅ P0: 100% (8/8)
🔄 P1: 75% (9/12)
🔄 P2: 80% (8/10)

🐛 버그: 4개 (1 Major ⚠️)

💡 다음: /qa-run 으로 테스트 계속
```

### --progress 옵션

```
📊 QA 진행률

████████░░ 83.3%

완료: 25/30
남음: 5개
예상 완료: 1시간 후
```

### --bugs 옵션

```
🐛 버그 현황

BUG-001 [Major] 회원가입 이메일 인증 - Open
BUG-002 [Minor] 검색 필터 UI - Fixed
BUG-003 [Minor] 프로필 이미지 크기 - Open
BUG-004 [Trivial] 오타 수정 - Open

Open: 3 | Fixed: 1 | Total: 4
```

### --next 옵션

```
📋 다음 할 일

1. TC-016: 검색 - 키워드 검색 (P1)
2. TC-017: 검색 - 필터 조합 (P1)
3. TC-018: 검색 - 정렬 (P1)

실행: /qa-run TC-016
전체: /qa-run --continue
```

## 상태별 권장 액션

| 상태 | 권장 액션 |
|------|----------|
| 테스트 대기 | `/qa-run` 실행 |
| 진행 중 | `/qa-run --continue` |
| 실패 있음 | 버그 수정 후 `/qa-run --failed` |
| 블록됨 | 블록 요인 해결 후 `/qa-run` |
| 완료 | `/qa-report` 생성 |

---

## 옵션 설명

| 옵션 | 설명 |
|------|------|
| `--progress` | 진행률만 간략히 표시 |
| `--bugs` | 버그 현황만 표시 |
| `--next` | 다음 할 일만 표시 |
| `--json` | JSON 형식으로 출력 |
| `--verbose` | 모든 테스트 케이스 표시 |

## 참조

- `/qa-run` - 테스트 실행
- `/qa-report` - 보고서 생성
- `/qa-plan` - 계획서 확인

# /solve-log - 문제 해결 진행 로그

> **🚨 중요**: 문서, 코드, 기타 확인 및 검증이 필요한 부분은 **전부 에이전트 사용 필수**. 에이전트를 적극 활용하고, 파일이 크면 분할해서 읽어라.

## 목적

진행 중인 문제 해결의 상태와 수집된 정보를 확인합니다.

## 사용법

```bash
/solve-log              # 모든 진행 중인 문제 표시
/solve-log PROB-001     # 특정 문제의 상세 로그
```

## 실행 절차

### Step 1: 활성 문제 확인

`.claude/problem-solving/active/` 디렉토리 스캔

### Step 2: 상태 표시

#### 전체 목록 (인자 없음)

```
============================================
[SOLVE-LOG] 진행 중인 문제 해결
============================================

 ID          | 문제 요약           | 단계      | 시작 시간
─────────────┼────────────────────┼──────────┼──────────
 PROB-001    | 로그인 API 500 에러 | 분석 중   | 2시간 전
 PROB-002    | 결제 실패           | 가설 검증 | 30분 전

 총 2건의 문제가 진행 중입니다.

============================================
```

#### 상세 로그 (ID 지정)

```
============================================
[SOLVE-LOG] PROB-001 상세 로그
============================================

 📋 문제 정보
 ─────────────────────────────────────────
 • ID: PROB-001
 • 문제: 로그인 API 500 에러
 • 시작: 2025-12-30 10:00
 • 현재 단계: Phase 3 (원인 분석)

 📊 진행 상황
 ─────────────────────────────────────────
 [✅] Phase 1: 문제 정의
 [✅] Phase 2: 정보 수집
 [▶️] Phase 3: 원인 분석
 [⬜] Phase 4: 가설 검증
 [⬜] Phase 5: 해결
 [⬜] Phase 6: 문서화

 📝 수집된 정보
 ─────────────────────────────────────────
 • 에러 메시지: Internal Server Error
 • 관련 파일: 3개
 • Git 커밋: 5개 분석됨

 🔍 현재 분석 내용
 ─────────────────────────────────────────
 5 Whys 진행 중:
 • Why 1: DB 쿼리 실패
 • Why 2: 컬럼 없음
 • Why 3: (분석 중...)

 💡 다음 단계
 ─────────────────────────────────────────
 • /solve 계속 - 분석 계속하기
 • /solve-report PROB-001 --draft - 현재까지 보고서

============================================
```

### Step 3: 파일 내용 표시

요청 시 관련 파일 내용 표시:
- `problem.md` - 문제 정의
- `analysis.md` - 분석 기록
- `hypotheses.md` - 가설 목록

## 출력 파일

읽기 전용 - 파일 수정 없음
